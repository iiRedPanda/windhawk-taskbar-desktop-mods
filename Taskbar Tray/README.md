# Taskbar Tray

Make room in the Windows system tray by hiding supported indicators you do not use. Tune the notification bell, battery icon, and Show Desktop button separately.

## Features

- Individual visibility settings for supported volume, network, battery, microphone, location, Studio Effects, Recall, and language indicators.
- Conditional bell visibility based on notifications and Do Not Disturb.
- Optional grayscale battery icon.
- Show Desktop width from 0 to 80 pixels; 0 hides the button.

## Settings

Choose which supported system indicators to hide in the mod's settings. Configure the notification bell separately to account for notifications and Do Not Disturb. Battery grayscale changes the battery icon's appearance.

Set the Show Desktop width to a value between 0 and 80 pixels. A value of 0 hides the button; the default is 12 pixels.

## Compatibility and status

Experimental source release. Compilation, the default tray layout, volume and bell hide/restore, Show Desktop width at 0 and 12, and restore-on-disable were checked on one Windows 11 installation. Hardware-dependent icons and notification-dependent bell modes remain unverified. Available icons depend on Windows version and hardware. Concurrent tray-tweak mods may apply overlapping overrides.
