# Taskbar Thumbnail Reorder

Reorder taskbar thumbnail previews by dragging them with the left mouse button.

## Usage

Hover over a taskbar app with multiple windows to open its thumbnail previews. Hold the left mouse button on a preview, drag it to the desired position, and release it.

## Settings

The inherited legacy-taskbar option is available for applicable Windows 11 replacement taskbars. This fork retains the original core behavior under its own mod identity; it does not claim a new reordering algorithm.

## Compatibility and status

Experimental source release. Compilation, repeated drags between two grouped File Explorer previews, a drag with a window on another display, and preview behavior after disabling were checked on one Windows 11 installation. Rapid repeated drags and Explorer restart behavior remain unverified. Running the original reorder mod concurrently can duplicate hooks.
